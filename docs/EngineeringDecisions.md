#EngineeringDecisions

##ED-001
Decision:
Java + Springboot for back-end framework

Reason: 
Industry standard backend framework with strong typing, excellent tooling and a large ecosystem.

##ED-002
Decision:
Using React for front-end framework.

Reason:
Provides component-based architecture, integrates well with REST APIs, widely used in the industry.

##ED-003
Decision:
Using PostgreSQL as the primary relational database.

Reason: Suitable for TriTracks highly structured and related data, exellent intregration with Springboot.

##ED-004
Decision:
Having domain modelling and achitecure completed before writing any code.

Reason:
Understanding the problem and identifying domain models leads to structured, nead, and well understood code later on.

##ED-005

Reason:
